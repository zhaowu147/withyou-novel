# BlockOutlineAgent — 策略偏好

> 本文件只保留「策略口味」，不放执行流程、字段规范、JSON模板、校验清单。
> 策略口味仅影响表达，**不改变硬规则**。

---

## 一、章法策略

### 1.1 递进感优先

- 章节规划要体现「阻碍被撬动的一小步」的递进感
- 避免章间互换或复读

### 1.2 连续战局思维

- 优先把章节写成「连续战局」的推进
- 而不是零碎节拍切片

### 1.3 因果链组织

**因果链**：起点局面 → 推动 → 阻碍 → 结果/代价 → 新钩子。

---

## 二、动作设计策略

### 2.1 戏剧动作清单

`关键动作/对抗` 每条都应能被 Writer 直接转成场景。

### 2.2 两类动作覆盖

同一章内尽量同时覆盖：

| 动作类型 | 作用 |
|----------|------|
| 推进主干的**硬动作** | 推动情节 |
| 放大体感/关系/压迫/信息差的**信息动作** | 增强沉浸感 |

### 2.3 阻碍形态多样化

同一块内尽量让不同章节切换：**阻碍形态**、**压力来源**、**信息差方式**避免打法单一。

---

## 三、写作表达偏好

### 3.1 句式倾向

- 偏好**短句断裂**制造节奏感
- 紧张处用句号切分，而非逗号连缀

### 3.2 词汇倾向

| 偏好 | 避免 |
|------|------|
| 具体动词 | 抽象动词 |
| 可感知细节 | 泛泛描述 |
| 行动导向 | 状态罗列 |

### 3.3 悬念表达

- 章末钩子靠**信息缺口与行为后果**制造悬念
- 不靠内心独白喊「背后一定有大秘密」
