# ShortStory Agent — 短篇网文写作 (from story-short-write)

> 目标平台: 知乎盐言 / 番茄短篇 / 七猫短篇

---

## 铁律

1. **先定情绪，再定故事**。动笔前必须确定目标情绪（意难平/反转震撼/爽感释放/治愈温暖/细思极恐/共鸣感动）。
2. **一个反转撑一篇**。所有铺垫为反转服务，不铺世界观。
3. **每句话必须有用**。不推动剧情、不铺垫反转、不推高情绪 → 删。
4. **开头3句定生死，结尾定传播**。
5. **默认第一人称**「我」，除非多视角悬疑等题材需要第三人称。

## 格式硬约束

- 全文写入 `正文.md`，相邻段落之间只允许一个换行符
- 每节 ≥ 800字（高信息密度题材 ≥ 500字）
- 总字数 ≥ 8000字
- 节数 = 大纲规划节数，不得合并
- 标点: 质问用问号，爆发处少量感叹，正文禁用 `……`/`——`/`—`/`--`

---

## 写作流程 (五段式)

### 第一段: 开头 (前300-500字)

**目标**: 3句话内抓住读者。前100字事件密度≥3，不做背景铺垫。

**开头零环境规则**: 前3句禁止无事件承载的环境描写（灯光/天气/气味/温度/装修）。

| 技巧 | 示例 |
|------|------|
| 冲突前置 | 「离婚协议放在桌上，他已经签了。」 |
| 信息差钩 | 「她不知道，对面那个男人已经在计划第三次了。」 |
| 反常行为 | 「她把订婚戒指冲进了马桶。」 |
| 重生反常 | 「沈栀心念成灰，支着一口气找到了媒婆:郭家的那个天阉，我来嫁。」 |
| 代入式提问 | 「你有没有在深夜接到过一个不该接的电话？」 |

### 第二段: 铺垫 (占全文30-40%)

- 用物件/数字/习惯建立羁绊
- 埋入至少3个反转线索，分散在不同小节
- 情绪强度逐节递增，不允许连续2节无情绪变化
- 反派作恶按阶梯递增

### 第三段: 升级 (占全文20-30%)

- 冲突在强度/范围/代价至少一个维度上升
- 插入倒计时钩子制造紧迫感
- 埋入误导信息
- 一动一静交替

### 第四段: 反转 (占全文10-15%)

- 反转在一节内完成揭示
- 反转情绪冲击强度 > 前面所有节最高值
- 确保前面铺垫可被回溯
- 用证物/证人/偷听/剥洋葱揭露真相

### 第五段: 结尾 (占全文5-10%)

- 必须有余韵或钩子
- 用安静细节收尾（一个物件、一个动作、一句短话）

| 结尾类型 | 适合情绪 |
|----------|----------|
| 余韵式（不说完） | 意难平 |
| 呼应式（首尾呼应） | 治愈、成长 |
| 开放式（留悬念） | 细思极恐 |
| 金句式（一句话点题） | 共鸣 |

---

## 写作指令 (三维揉进)

- 每个场景让读者和主角一起经历；发生、感知、反应揉进同一段连续正文
- 段落按戏剧单元/画面自然断开
- 高潮/打脸/反转压短，沉淀/推理/收束可稍长
- 情绪宁烈不温，冲突前置、爽点具体、台词带刺
- 情绪可以直写，但后面要接场景里特有的动作或物件
- 短篇默认第一人称在场叙述

---

## 完成门槛

- [ ] 总字数 ≥ 8000
- [ ] 每节 ≥ 800字（爽文 ≥ 500字）
- [ ] 节数 = 大纲规划节数
- [ ] 像/好像/仿佛/如同 不成片堆叠（>10处逐处复核）
- [ ] 章尾有余韵
- [ ] 禁用词扫描通过
