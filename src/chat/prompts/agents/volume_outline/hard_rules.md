# VolumeOutline Agent — 错误案例

---

## 案例1：块故事写成任务清单

**错误**：
```
块故事：主角进入宗门→参加考核→结识女主→获得传承
```

**正确**：
```
块故事：在宗门考核的压力下，主角为证明天赋，历经质疑与考验，最终在生死对决中逆转局势，赢得核心弟子身份
```

---

## 案例2：相邻块可互换

**错误**：
```
块1：主角在东域修炼，突破到筑基中期
块2：主角在东域修炼，突破到筑基后期
```

**正确**：相邻块必须有权力/信息/关系上的可观察推进

---

## 案例3：跨卷越界

**错误**：
```
块故事：主角获得神兵后，一路势如破竹，最终统一整个修仙界
```

**正确**：块故事的格局必须匹配本卷的范围

---

## 案例4：转线类型选择不当

**错误**：卷有5个块，全部是主线块

**正确**：必须至少包含1个非主线块
