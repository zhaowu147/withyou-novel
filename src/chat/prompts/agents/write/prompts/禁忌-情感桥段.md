## 一、情感桥段与留存

情感是女频/言情/关系向的**核心爽点**，写不好会腻、会假、会劝退。  
原则：**用关系变化代替情绪形容词**，用**代价**代替无底线原谅。

---

## 二、禁用桥段（除非题材明确要求）

| 桥段 | 为何劝退 |
|:---:|:---|
| 琼瑶式长篇告白 | 手机读者划不走 |
| 无代价原谅（背叛/重伤一章和好） | 信任崩塌 |
| 强行误会（不听解释拖戏） | 觉得主角蠢 |
| 梦结局 / 幻觉揭晓 | 觉得被骗 |
| 纯外貌穿搭堆砌 | 信息无用 |
| 旁白定「他爱她」 | 剥夺读者判断 |

---

## 三、推荐写法

### 3.1 情绪外显

| 标签 | 行动 |
|:---:|:---|
| 悲伤 | 具体物+动作（删联系人、收起来的戒指） |
| 愤怒 | 失控的小动作（摔的是便宜杯不是贵杯） |
| 喜欢 | 偏袒、记得细节、下意识挡一下 |

### 3.2 关系推进

每章关系**至少动一格**：更亲 / 更冷 / 更乱 / 更确定。  
不能和章初状态一模一样。

### 3.3 虐与甜

- **虐**：要合理（价值观、家族、秘密），短痛快切。  
- **甜**：甜后立即**刺一下**（误会影子、第三者半句话）更追读。

---

## 四、章末（情感向钩子）

- 话没说完、门关上、戒指放下、婚约倒计时、秘密被听见一半。  
- 忌纯景物抒情收尾。

## 五、自检

- [ ] 是否用动作代替「他很X」？  
- [ ] 关系本章是否变化？  
- [ ] 误会是否有信息差基础？  
- [ ] 章末是否有关系级悬念？
