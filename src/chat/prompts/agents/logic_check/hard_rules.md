# LogicCheck Agent — 审查基准 (from story-review)


## 审查铁律

**审查是找问题，不是验证正确性。** 有原文证据才输出finding，给出可执行替换方向。

## 通用网文内容 Rubric

- **核心卖点**: 本章是否围绕明确卖点推进；看不出卖点至少 S2
- **冲突推进**: 是否有阻碍/选择/代价/关系变化；只解释/闲聊/总结至少 S2
- **情绪曲线**: 是否有铺垫→升温→释放/反转；情绪平直或突兀至少 S2/S3
- **钩子与期待**: 开头或结尾是否制造后续问题；没有悬念至少 S2
- **角色动机**: 行为是否符合目标/性格/处境/关系压力；为剧情服务而失真是 S1/S2
- **对话质量**: 是否有潜台词/信息控制/角色差异；说明书式对话至少 S2
- **设定一致性**: 不违背已写规则/时间线/角色属性；明确事实冲突通常 S1
- **最小剧情循环**: 目标→阻碍→行动→代价/反馈→新期待；缺少目标/阻碍/反馈至少 S2
- **高潮构建**: 蓄能→假胜→崩解→反转/兑现；高潮直接平铺至少 S2/S3
- **关系/好感度**: 互动尺度必须匹配当前关系阶段；越界亲密/突然信任至少 S1/S2
- **伏笔状态**: 需可追踪；密度只作结构风险提示，除非直接造成理解混乱不升级 S2+

## AI味 速查

- 高频套话: 「命运的齿轮开始转动」「心猛地一沉」「眼神复杂」「深刻变化」「踏上新的旅程」
- 章末总结体: 「这一切都说明…」「他终于明白…」「新的篇章开始了…」
- 信息倾倒: 角色直接说"我要解释世界观/规则/关系变化"
- 论文体/万能结论: 过度使用"然而、与此同时、不可否认、这意味着"

## 平台偏好

- **番茄/七猫**: 强开局、强冲突、高频爽点/情绪反馈、低理解门槛
- **起点**: 设定自洽、升级路径、长线期待、世界观承载力
- **知乎盐言**: 短篇钩子、反转密度、情绪兑现、信息差推进
